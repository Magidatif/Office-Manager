# Daily Office Manager — نظام إدارة ومتابعة الأعمال اليومية
### مخصص للمكتب الفني لمدير فرع الهيئة العامة للرعاية الصحية

تطبيق ويب متكامل (Full-Stack Production-Ready System) مصمم خصيصاً لإدارة وتنظيم وتسجيل وتوثيق ومتابعة كافة الأعمال اليومية والتكليفات والمراسلات والاجتماعات الإدارية داخل المكتب الفني لمدير فرع الهيئة.

---

## 🏗 البنية التقنية (Architecture)

تم بناء النظام بالكامل وفق المعايير السحابية الحديثة لشركة **Cloudflare** لضمان أعلى مستويات السرعة، والاستقرار، والتوافر اللحظي دون الحاجة إلى خادم تقليدي:

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **Icons & Charts:** Lucide React + Recharts
- **Backend API:** Cloudflare Workers باستخدام إطار عمل Hono السريع
- **Database:** Cloudflare D1 (قاعدة بيانات علائقية SQLite موزعة عالمياً)
- **Object Storage:** Cloudflare R2 لتخزين المرفقات والوثائق الإدارية
- **Scheduled Jobs:** Cloudflare Cron Triggers للفحص الصباحي التلقائي للمهام والتنبيهات
- **Security:** Web Crypto API (JWT HS256 + SHA-256 مع Salt لكلمات المرور)

## 📋 الوحدات الإدارية الرئيسية بالنظام

1. **لوحة التحكم (Dashboard):**
   - 10 بطاقات إحصائية رئيسية محسوبة لحظياً من قاعدة البيانات (إجمالي المهام، مهام اليوم، قيد التنفيذ، المكتملة، المتأخرة، العاجلة، في انتظار الرد، مستحقة غداً، نسبة إنجاز الأسبوع، المخاطبات النشطة).
   - رسوم بيانية تفاعلية لتوزيع المهام حسب الحالة والأولوية.
   - أقسام سريعة لأهم 5 مهام عاجلة، المهام المقتربة من موعدها، اجتماعات اليوم، وسجل النشاطات.

2. **إدارة المهام والتكليفات (Daily Task Management):**
   - تسجيل كامل لبيانات المهمة (الأولوية، جهة التكليف، المسؤول، تاريخ البدء والاستحقاق، نسبة الإنجاز).
   - مهام فرعية (Subtasks) بنسب إنجاز تلقائية تراكمية.
   - تتبع تأجيل المواعيد وتوثيق أسباب التأجيل وعدد مراته تلقائياً.
   - نسخ المهام، أرشفتها، وحذفها الآمن.
   - سجل متابعة وتعليقات زمني لكل مهمة.

3. **سجل الأعمال والإنجازات اليومية (Daily Work Log):**
   - توثيق التسلسل الزمني للأعمال اليومية مع تحديد أوقات البدء والانتهاء والنتائج والمعوقات.
   - زر **"إضافة إنجاز سريع"** للتوثيق اللحظي بضغطة زر واحدة.
   - **"تقرير نهاية اليوم"** الآلي الذي يجمع ما تم إنجازه، الأعمال المعلقة، المعوقات، والمطلوب متابعته غداً مع إمكانية الطباعة الفورية.

4. **إدارة المخاطبات والمراسلات (Correspondences):**
   - سجل إلكتروني للمكاتبات (وارد، صادر، مذكرات عرض، تكليفات، قرارات، مكاتبات داخلية).
   - إمكانية **تحويل أي مكاتبة إلى مهمة متابعة فورية بنقرة واحدة** مع الربط التبادلي.

5. **الاجتماعات والقرارات (Meetings & Decisions):**
   - توثيق محاضر الاجتماعات وجداول الأعمال وقوائم الحضور.
   - قيد القرارات والتوصيات الصادرة وتحويل أي توصية أو قرار إلى مهمة عمل تنفيذية.
   - شاشة مستقلة لمتابعة تنفيذ توصيات كافة الاجتماعات.

6. **مركز المتابعة (Follow-up Center):**
   - شاشة موحدة مقسمة بتبويبات ذكية (متابعة اليوم، غداً، في انتظار رد، متأخرة، في انتظار اعتماد، خلال الأسبوع، معلقة).
   - تسجيل إجراءات المتابعة (قناة المتابعة، المسؤول، النتيجة، الرد المستلم، والخطوة القادمة) مع سجل زمني تاريخي لكل موضوع.

7. **التقويم الإداري والمواعيد (Calendar & Reminders):**
   - تقويم تفاعلي يتعامل بدقة مع التوقيت المحلي لجمهورية مصر العربية (`Africa/Cairo`).
   - إمكانية تفعيل إشعارات المتصفح المحلية لتنبيه المستخدم بالمواعيد الهامة.

8. **بنك المستندات والأرشيف الإلكتروني (Documents & Archive):**
   - أرشفة المستندات (PDF, Word, Excel, صور) مع بياناتها الوصفية والتصنيفات والكلمات المفتاحية.
   - رفع وتنزيل آمن مرتبط بمستودع Cloudflare R2.

9. **التقارير والإحصائيات (Reports & Analytics):**
   - 10 تقارير إدارية رسمية معتمدة قابلة للتصفية بحسب التاريخ والإدارة.
   - تصدير فوري إلى ملفات Excel (CSV) بترميز `UTF-8 BOM` لمنع تشوه الحروف العربية في Microsoft Excel.
   - صيغة طباعة رسمية بالترويسة والاعتمادات الإدارية.

10. **البحث المتقدم الشامل (Global Search):**
    - بحث فوري في كافة أرجاء النظام (المهام، المخاطبات، الاجتماعات، الأرشيف، سجلات العمل) مدعوم باختصار لوحة المفاتيح (`Ctrl + K`).

11. **الإعدادات والنسخ الاحتياطي (Settings & Backup):**
    - تحديد مواعيد بداية ونهاية يوم العمل وساعات التنبيه.
    - تصدير نسخة احتياطية كاملة من قاعدة البيانات بصيغة JSON.
    - تغيير كلمة المرور وتأمين الحساب.

## 🚀 دليل التشغيل المحلي (Local Development)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث، تم التحقق والتطوير على v25.8.2)
- npm

### 1. تثبيت الحزم
```bash
npm install
```

### 2. بناء حزمة الخادم (Worker)
```bash
npm run build:worker
```

### 3. تشغيل خادم التطوير الشامل
```bash
npm run dev
```
سيفتح التطبيق على الرابط: `http://localhost:5173`

> **ملاحظة للمطور:** يتضمن خادم Vite المحلي بيئة محاكاة كاملة لقاعدة بيانات Cloudflare D1 عبر `node:sqlite` المدمج، مما يتيح تشغيل وحفظ واسترجاع كافة البيانات محلياً دون الحاجة لربط فوري بحساب Cloudflare.

### 4. تسجيل الدخول الافتراضي
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123@office`

## ☁️ خطوات النشر على Cloudflare (Cloudflare Deployment Guide)

للنشر على حساب Cloudflare الخاص بك:

### الخطوة 1: تسجيل الدخول إلى Cloudflare عبر Wrangler
```bash
npx wrangler login
```

### الخطوة 2: إنشاء قاعدة بيانات D1
```bash
npx wrangler d1 create daily-office-db
```
سيظهر لك في موجه الأوامر مخرجات تشبه:
```toml
[[d1_databases]]
binding = "DB"
database_name = "daily-office-db"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```
انسخ الـ `database_id` وضعه في ملف `wrangler.toml` بدلاً من القيمة المؤقتة.

### الخطوة 3: إنشاء مستودع R2 للمرفقات
```bash
npx wrangler r2 bucket create daily-office-attachments
```

### الخطوة 4: تطبيق الـ Migrations والبيانات الأولية على Cloudflare D1
```bash
# تطبيق هيكل الجداول
npx wrangler d1 execute daily-office-db --remote --file=./migrations/0001_initial_schema.sql

# إدراج الإدارات والمستخدم الافتراضي
npx wrangler d1 execute daily-office-db --remote --file=./migrations/0002_seed_data.sql
```

### الخطوة 5: بناء واجهة المستخدم وWorker
```bash
npm run build
npm run build:worker
```

### الخطوة 6: النشر النهائي (Deployment)
```bash
npx wrangler deploy
```

سيزودك Wrangler فوراً برابط الإنتاج المباشر، مثل:
`https://daily-office-manager.<your-subdomain>.workers.dev`

## 🔒 تنبيهات الأمان والخصوصية

- النظام مخصص حصرياً للمهام، التكليفات، والمخاطبات الإدارية والتنظيمية لمكتب مدير الفرع.
- **تنبيه:** لا تضع بيانات مرضى أو ملفات طبية أو بيانات شخصية حساسة داخل النظام.
- تم تأمين الجلسات برموز JWT المشفرة باستخدام خوارزمية HMAC-SHA256 المدعومة من Web Crypto API.
